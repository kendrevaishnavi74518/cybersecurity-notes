## Windows CLI Basics

- The Command Prompt(CMD) is a text-based interface within the Windows OS, where user types commands instead of clicking around icons.

## Commands

1. cd- Shows full path of current directory, also used for changing directories.
2. dir - Lists all fils & folders present in current directory.
   - dir /a: Lists all hidden items.
   - dir /s file_name : Used to find files on the disk. The '/s' flag tells Windows to search all subfolders starting from current directory, if file exists.
3. type <file_name> - Used to read contents of a file.
4. systeminfo - Gives details of the OS.
5. ipconfig - Shows network configuration.

## Operating System Security

- Computer hardware refers to all computer parts, we can touch. Hardware includes screen,keyboard,printer, USB flash memory, desktop board.
- Desktop board contains CPU & memory chips(RAM). It is usually connected to storage device(HDD or SSD). It is the main part of a computer.
- operating systems intended for servers, examples include MS Windows Server 2022, IBM AIX, and Oracle Solaris.
<br>

- **CIA Triad**
   1. Confidentiality - To ensure that sensitive data is accessible only by authorized person.
   2. Integrity - To ensure that the data remains true & accurate, unaltered throughout its lifetime.
   3. Availability - To ensure that the system is available to use whenever required.
<br>

- **Authentication & Weak Passwords**
<br>

- Authentication is the act of verifying the identity, it is achieved by password or PIN code, biometrics, OTPs.
- Passwords are the most common ways of authentication.
- Weak file permissions make it easy to attack on confidentiality & integrity.
<br>

- **Malicious Programs**
   1. Trojan horses - Gives the attacker access to our system, allowing them to read or even modifying the files.
   2. Ransomware - It attacks availability. It encrypts files, and demands a certain amount(ransom) to restore availability.
   - Encryption converts data into unreadable text, that can only be read again by decrypting it with the correct key or password.
