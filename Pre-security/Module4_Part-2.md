## JavaScript Basics

- JavaScript was initially developed to run on client machines, in particular, within a web browser.
- Variable can be thought of as a place where we store a value, that can be read in future or can be modified.
- 'let' is used to declare a variable, 'const' is used to declare constants.
'Math.random()' is a method used to gets random decimal numbers between 0(including) and 1(not included).
- 'parseInt()' mathod takes user input & converts it from text to integer.
<br>

- if-else
   - if checks whether a condition is true.
   - If it is false, else if checks another condition.
   - If all conditions are false, else runs.
- while = Check condition → run code → check again → stop when false.
- Not equal to is written as '!==' in Javascript.
