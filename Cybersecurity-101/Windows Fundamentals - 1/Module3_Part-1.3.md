# Windows Settings and Control Panel
Windows provides two main locations for changing system configurations:
* **Settings**
* **Control Panel**

## Settings
* The **Settings** menu was introduced in **Windows 8**.
* It is designed to provide a simpler and more user-friendly way to manage system settings.
* In **Windows 10**, Settings became the primary location for most system configuration tasks.
* It can be accessed through the **Start Menu**.
* Examples include changing wallpaper, network settings, personalization, and other system options.

## Control Panel
* **Control Panel** has been available in Windows for a long time.
* It is used for more **advanced or complex system settings**.
* Common tasks include:
  * Adding or configuring printers
  * Uninstalling programs
  * Managing network adapters
  * Viewing installed applications

## Programs and Features
To view installed applications:
1. Open **Control Panel**.
2. Select **Programs**.
3. Select **Programs and Features**.
4. A list of installed applications is displayed, including:

   * Application name
   * Publisher
   * Version
This can help identify and verify software installed on the system.

## Settings vs Control Panel
* Both **Settings** and **Control Panel** can be accessed from the **Start Menu**.
* Settings is generally used for **common and simpler configurations**.
* Control Panel provides access to **more detailed and advanced options**.
* Some settings may start in Settings but open a Control Panel window for advanced configuration.

### Example
**Settings → Network & Internet → Change adapter options**

This can open a **Control Panel** window containing network adapter settings.

## Searching for Settings
If you are unsure where a particular setting is located:
1. Open the **Start Menu**.
2. Search for the required setting, such as **wallpaper**.
3. Select the most relevant result.
4. Windows will open the appropriate Settings or Control Panel page.

## Task Manager
* **Task Manager** is a Windows utility used to monitor and manage applications and processes currently running on the system.
* It also provides information about system resource usage, including:
  * **CPU** utilization
  * **RAM/Memory** utilization
  * Other performance information

## Opening Task Manager
* Task Manager can be accessed by **right-clicking the taskbar** and selecting **Task Manager**.

## Task Manager Views

### Simple View
* Task Manager initially opens in **Simple View**.
* This view provides limited information about running applications.

### Detailed View
* Clicking **More details** opens the full Task Manager interface.
* It provides more detailed information about:
  * Running applications
  * Processes
  * CPU usage
  * Memory usage
  * System performance

### Key Points
* **Task Manager** = Monitors and manages running processes and applications.
* It helps monitor **CPU and RAM usage**.
* **Simple View** shows basic information.
* **More details** provides comprehensive process and performance information.
